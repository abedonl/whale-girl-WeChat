使用步骤
  1. 确保微信 Windows 版已登录
  2. 确保已装 Python 3.10+：py --version
  3. 首次使用先装依赖：pip install wechatauto-replica
  4. 点上面的「启动桥接」按钮
  5. 把微信窗口拖出来别被挡住，大肥鱼就会开始自动回复
